# KvmClient — приложение для рабочего ПК

C#, .NET 10, Avalonia 12.1.5. Только Windows (перехват клавиатуры — низкоуровневый хук Win32).

## Сборка и запуск

- Visual Studio 2026: открыть `KvmClient.slnx`, запустить.
- VS Code: открыть папку `host-app`, **Терминал → Запустить задачу** — «Сборка», «Запуск» или
  «Публикация (один exe)» (результат — `host-app/publish/KvmClient.exe`).
- Командная строка: `dotnet run --project KvmClient -c Release`.

## Работа

1. Указать IP и порт платы (по умолчанию 192.168.50.10:50000), «Подключиться».
2. Изображение удалённого ПК появляется в окне; под ним — состояние (видео, HDMI, USB) и журнал событий.
   Нет пакетов от платы дольше 1 с — серый экран «Нет связи».
3. **Ctrl+Alt+Q** — режим управления: окно на весь экран, клавиатура и мышь передаются удалённому ПК
   (клавиши — по скан-кодам, мышь — абсолютными координатами). Повторное Ctrl+Alt+Q или потеря фокуса — выход.
   **Ctrl+Alt+End** передаёт удалённому ПК Ctrl+Alt+Del.

## Файлы

| Файл | Назначение |
|---|---|
| KvmLink.cs | протокол с платой (UDP): запросы, сборка обновлений из плиток |
| RemoteInput.cs | состояние клавиатуры и мыши удалённого ПК, отправка на плату |
| Win32Input.cs | перехват клавиатуры, коды HID, ограничение курсора окном |
| MainWindow.axaml(.cs) | окно: подключение, вывод изображения, режим управления |

Протокол описан в `board/docs/DESIGN.md` и `board/firmware/app/kvm_proto.h`.
